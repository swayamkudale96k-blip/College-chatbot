The College Inquiry Chatbot is an AI-powered virtual assistant designed to help students, parents, and visitors get instant answers to college-related queries. It provides information about admissions, courses, fees, eligibility criteria, campus facilities, placements, academic schedules, and more, reducing the need for manual support.

🚀 Features
📚 Course Information
📝 Admission Guidance
💰 Fee Structure Details
🎯 Eligibility Criteria Information
🏫 Campus Facilities Overview
📅 Academic Calendar & Events
💼 Placement and Career Information
🤖 AI-Based Natural Language Processing
⏰ 24/7 Availability
📱 User-Friendly Interface
